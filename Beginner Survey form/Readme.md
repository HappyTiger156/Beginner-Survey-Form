Name: KTK

ဒီ project က beginner level အတွက် HTML နဲ့ CSS သုံးပြီးရေးထားတဲ့ survey form assignment ဖြစ်ပါတယ်။

## Description

ဒီ form ကို HTML နဲ့ structure ဆောက်ထားပါတယ်။  
Personal Details နဲ့ Additional Information ကိုခွဲဖို့ `fieldset` ကိုသုံးထားပါတယ်။

Personal Details ထဲမှာ name, address, email, phone number နဲ့ gender selection တွေပါပါတယ်။

Additional Information ထဲမှာ background information ရေးဖို့ textarea ထည့်ထားပါတယ်။
